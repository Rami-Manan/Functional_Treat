# Functional Treat – Data Analyzer and Transformer

## 📌 Project Title

**Functional Treat – Data Analyzer and Transformer**

---

## 📖 Description

Functional Treat is a **menu-driven Python program** developed to analyze and transform numerical data stored in a **one-dimensional (1D) list**.

The program allows the user to enter numerical data and perform different operations such as:

- Displaying basic data statistics
- Calculating factorial using recursion
- Filtering data using a lambda function
- Sorting data in ascending or descending order
- Calculating maximum, minimum, sum, and average
- Demonstrating the use of the `global` keyword
- Using user-defined functions
- Using `map()`, `filter()`, and `sorted()`
- Using function documentation through `__doc__`

The main purpose of this project is to demonstrate important Python programming concepts through a practical data analysis application.

---

## 🎯 Objectives

The main objectives of this project are:

1. To create a menu-driven Python application.
2. To demonstrate the use of Python built-in functions.
3. To create and use user-defined functions.
4. To demonstrate recursion using factorial calculation.
5. To use lambda functions with `filter()`.
6. To demonstrate the `global` keyword.
7. To return and display useful information from functions.
8. To perform sorting operations on list data.
9. To calculate basic statistics from a numerical dataset.
10. To provide a simple and interactive console-based user interface.
